#   CONTEXTO ADMINISTRATIVO

El sistema del gimnasio maneja una estructura centralizada, ya que el administrador controla los procesos principales como usuarios, ventas e inventario desde un solo lugar. Esto ayuda a mantener mejor organización, seguridad y control de la información.
El auditor supervisa y revisa los movimientos del sistema para verificar que todo funcione correctamente.
